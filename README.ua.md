# Додаток «Телефонна книга»

Цей додаток дозволяє користувачам додавати та видаляти контакти (телефонну книгу). Додавання та видалення контактів доступне **тільки для зареєстрованих користувачів**.

## Реєстрація

1. Реалізувати реєстрацію користувача при натисканні кнопки "Register".  
   Шаблон модалки для реєстрації користувача є у паршалах. Можна використати `<template>` або безпосередньо взяти розмітку з паршала.
2. Для відкриття/закриття модалки використати бібліотеку **BasicLightbox**.
3. Після успішної реєстрації користувач отримує **токен**, який потрібно зберігати у `localStorage`.
4. Після успішної реєстрації, зареєстрований користувач має доступ **тільки до сторінки Contacts**.

## Логін

1. Реалізувати логінізацію користувача при натисканні кнопки "LogIn".  
   Шаблон модалки для логінізації користувача є у паршалах. Можна використати `<template>` або безпосередньо взяти розмітку з паршала.
2. Для відкриття/закриття модалки використати бібліотеку **BasicLightbox**.
3. Після успішного логіну користувач отримує **токен**, який потрібно зберігати у `localStorage`.
4. Після успішного логіну, зареєстрований користувач має доступ **тільки до сторінки Contacts**.

## Сторінка Contacts

1. На сторінці Contacts є форма для створення нових контактів.  
   Після успішного створення контакт відображається на сторінці (додається до списку `<ul>`).
2. Після оновлення сторінки повинні підтягуватися всі контакти з бекенду і відображатися у `<ul>`.
3. Реалізувати видалення контактів. Після видалення список контактів на сторінці має оновлюватися.
4. При натисканні кнопки "LogOut" користувач розлогінюється, токен видаляється, і стає доступною лише **головна сторінка**.
